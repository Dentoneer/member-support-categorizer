# Stage 2 Implementation Plan

> Executed inline (superpowers:executing-plans) overnight. The spec is the binding authority:
> `docs/superpowers/specs/2026-10-29-stage2-design.md`.

**Goal:** PII-safe summaries, RAG over category guidelines with Vector Search, a Job, and Model
Serving with inference tables. The work lands as a PR on top of stage 1.

## Global Constraints
- Same as the stage 1 plan: names in `settings.py`; idempotent writes; `UserFacingError` for every
  failure Marco can hit; no secrets or emails in code; notebooks thin, with a "What you'll learn" box.
- New names:
  - table `category_guidelines`;
  - index `category_guidelines_index`;
  - VS endpoint `support-vs`;
  - embedding endpoint `databricks-gte-large-en`;
  - job `support-categorizer-refresh`;
  - serving endpoint `support-categorizer`;
  - model alias `challenger`;
  - models `dspy_rag_zero_shot`, `dspy_rag`.
- Notebook pins add `databricks-sdk==0.157.0` where the notebook uses Vector Search, Jobs or Serving.

## Review Focus
1. Rerunning 08 when the endpoint/index already exist must reuse them (no "already exists" crash).
2. The VS endpoint or index is still provisioning, so a query fails: wait with a timeout and a
   plain-English message; never hang forever.
3. Retrieval failure for one call means empty guidelines for that call, and the batch continues.
4. A category added or renamed in the app ends up in `category_guidelines` with the right text.
5. Pickling the program with a retriever (MLflow logging) must not try to pickle a live client.

## Tasks
1. **PII** (`pii.py`, instruction changes in `categorizer.py` / `sql.py`). Tests: each pattern hits
   and misses; `pii_rate`; both instructions mention the rule.
2. **Guidelines** (`guidelines.py`): `ABCD_GUIDELINES_URL`, `DISPLAY_TO_ONTOLOGY`,
   `parse_guidelines(json) -> list[dict]`, `guideline_rows(tax, abcd) -> DataFrame`. Tests: 55
   mapped, every ontology label has text; rename uses the original's text; an added label uses its
   description; a retired label is excluded.
3. **Retrieval** (`retrieval.py`): `retrieval_query(transcript)`, `format_guidelines(hits)`,
   `GuidelineRetriever(index_name, k, client_factory)` with lazy client, `__getstate__` dropping the
   client, `__call__(text) -> str`, and `recall_at_k`. `ensure_endpoint`, `ensure_index` and
   `wait_until_ready` are idempotent, with a timeout. Tests use a fake client: reuse when existing,
   timeout message, pickle roundtrip, query failure gives "".
4. **Program retriever + registry champion/challenger** (`categorizer.py`, `registry.py`). Tests: the
   program calls the retriever only when guidelines are empty; `promote_if_better` logic; resources
   list built.
5. **Notebook 08** plus guidelines table writing (`tables.write_guidelines` with CDF). Spark test:
   write twice gives 55 rows, CDF property set.
6. **Job** (`jobs.py`: `job_tasks(repo_root, settings) -> list[Task]`, `upsert_job`) plus notebook 06.
   Tests: task graph, dependencies, base parameters; upsert updates an existing job by name.
7. **Serving** (`serving.py`: `endpoint_config`, `upsert_endpoint`, `serving_payload`) plus notebook
   09. Tests: config has the AI Gateway inference table, scale to zero, champion version.
8. **Defaults & docs**: app default = best model; 04 picks the best DSPy model; 05 PII rule;
   README/STUDY/STATE.
9. **Final review** (fresh opus reviewer), fix pass, PR.
